# BiliLiveAgent

B 站直播间弹幕智能体：常驻 Windows 系统托盘，只读取直播间的弹幕与互动事件，由 DeepSeek 生成回复并全自动参与聊天。
**不拉取、不播放任何直播音视频。**

## 它能做什么

- **只读弹幕与互动事件**：普通弹幕、点名/回复、醒目留言、礼物、上舰、进场、开播状态；同时可读取公开的房间元数据（标题、主播、分区、公告、人气）帮助理解语境。
- **全自动互动**：周期性汇总最近弹幕交给模型判断，可自主选择话题或保持沉默；支持点名优先、关键词优先、冷场主动抛话题。
- **人格与记忆**：多张人格卡（结构化编辑 + Markdown 导入导出）；长期保存房间摘要，并按 UID 记录观众的公开互动偏好与称呼。
- **频率完全可控**：最短发言间隔、每分钟/每小时上限、活跃度自适应、静默时段；长回复可分段发送，每段都计入配额。
- **安全边界**：不可关闭的违法/色情低俗/暴力自伤/隐私泄露/冒充身份拦截；防提示词注入；连续失败或风控自动熔断并切只读。
- **成本可见**：每日调用次数与 token 预算、本次/今日/累计用量与费用估算，超预算自动停止发言。

## 快速开始（免安装便携版）

1. 打包后有两种形态（都不需要安装、不写注册表、不需要管理员权限）：
   - 免安装文件夹：解压 `release\BiliLiveAgent-0.1.0-portable-win64.zip`，运行里面的 `BiliLiveAgent.exe`；
   - 直接运行 `release\win-unpacked\BiliLiveAgent.exe`。
   - 说明：单文件 exe（`--win portable`）还依赖 winCodeSign 解压符号链接，需要管理员权限或开启 Windows 开发者模式；当前默认产出文件夹/压缩包形态。
2. 首次进入「设置与诊断」：
   - **B 站账号**：点「扫码登录」用手机 B 站扫码（确认时建议选“记住我/长期”）；或点「浏览器导入」自动检测本机 Chrome / Edge / Firefox 的登录态。
   - **DeepSeek API Key**：填入官方 Key，密钥用 Windows DPAPI 加密保存在本机。
3. 回到「直播控制台」填写直播间房号，点「读取房间信息」确认可达，再点右上角「开始」。
4. 关闭窗口会缩到系统托盘并在后台继续运行；需要完全退出请使用托盘菜单的「退出应用」。

### 从源码运行

```bash
npm install
npm run build     # 构建主进程、预加载与渲染层
npm run dev       # Vite 开发服务器 + Electron 热启动
npm test          # 模拟收发的冒烟测试（不接触真实直播间）
npm run dist      # 产出 Windows x64 便携版
```

## 界面

| 模块 | 内容 |
| --- | --- |
| 直播控制台 | 房间信息、连接状态、实时弹幕流、发送与拦截记录、只读暂停、手动试发（需勾选确认） |
| 人格管理 | 人格卡列表与启用、结构化编辑、Markdown 导入导出、AI 身份规则 |
| 记忆管理 | 房间摘要编辑、按 UID 的观众记忆搜索/编辑/删除 |
| 设置与诊断 | 账号、DeepSeek 参数与预算、频率与安全规则、房间生命周期与计划时段、数据保留、日志与诊断 |

## 数据存放

- 便携版：数据目录在 exe 旁的 `BiliLiveAgent-Data\`（配置、人格、记忆、日志、发送记录）。
- 源码运行：项目根目录 `data\`。
- `secrets\*.bin` 保存 DPAPI 加密的 DeepSeek API Key 与 B 站登录凭据，只能由当前 Windows 用户在本机解密；复制数据目录到其他电脑不会带走密钥。
- 导出功能只导出配置、人格与记忆，不含任何密钥或凭据。

## 安全与合规

- 所有弹幕、昵称、标题、公告都被视为不可信数据：无法改写人格、索取密钥或控制本应用。
- 自动发言默认关闭，需手动点「开始」；可以随时切「只读暂停」继续观察而不发言。
- 真实发送测试请在自己的测试直播间进行，界面上的「真实发送一条」必须勾选确认才会执行。
- 请遵守 B 站社区规范与直播间规则，合理设置频率，避免刷屏。

## 参考与致谢

- 配置与人格体验参考 [WeChatAgent](https://github.com/sourcepro5/WeChatAgent)（仅借鉴交互与字段设计，未复制其代码）。
- B 站扫码登录与凭据持久化的思路参考 [dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)（MIT）；该仓库不含直播弹幕实现，本项目的直播弹幕协议为自行实现。
- 直播弹幕读取基于 B 站公开直播弹幕 WebSocket 协议（`ws` + zlib/brotli 解包），发送走 `msg/send` 并识别平台风控返回码。
